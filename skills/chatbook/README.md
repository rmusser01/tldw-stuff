# Chatbook note adaptations

These MIT-licensed adaptations derive from Notion Labs skills published in
OpenAI's skills repository. They replace Notion-specific account setup, databases,
page operations and branding with actual Chatbook local note tools and Markdown.
They preserve author credit, original license text and source/output hashes.

- [chatbook-meeting-preparation](chatbook-meeting-preparation/README.md): source-backed agendas and pre-reads, with six adapted meeting templates.
- [chatbook-knowledge-capture](chatbook-knowledge-capture/README.md): reusable decisions, procedures, FAQs, reference notes and lessons learned.

The tools target local database notes. Drafting works from supplied text;
persistent reads/writes require the appropriate enabled host tools. Neither
adapter assumes Notion-like relations, database properties or access controls.
Updates require full current content and a reliable version; otherwise the skill
returns a reviewable draft. The pinned note search/read tools do not expose versions.
