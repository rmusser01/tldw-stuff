## Adding an item

Each skill belongs in its own directory with its native SKILL.md and supporting files. State required tools, permissions, and tested host support. For Chatbook, document a verified directory import through its skills library; other hosts need their own verified instructions.

Follow [CONTRIBUTING.md](../CONTRIBUTING.md) and use the
[content README template](../templates/content-README.md).
Add a relative link and short description here when publishing an item.
