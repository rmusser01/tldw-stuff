## Import and requirements

Follow the [directory import guide](../../IMPORT.md). Select this exact directory
or its [SKILL.md](SKILL.md), preserving all accompanying files. Import does not
install packages, approve scripts, supply accounts or execute skill instructions.

The interview can use supplied facts, but the unchanged source explicitly requests subagents for environmental fact-finding. That step needs a host with authorized delegation and appropriate tools; Chatbook import does not supply it. This is grilling itself, not the grill-me alias. Import does not begin an interview or authorize executing its resulting plan.
