# Text and artwork scope

Character text: original **tldw-project** contribution, [Apache-2.0](LICENSE).

Adapted from the existing [Byte Buddy](../../buddy-packs/byte/README.md), pinned to collection commit `89a9fbfbc9bd6057b749518a30935205e8682bf6`. Its original atlas, archive, mappings and notices are unchanged. Artwork retains **Apache-2.0** for applicable project contributions; reference and character rights remain separate. See [artwork license](ART_LICENSE.txt) and source provenance.

Images were prepared using built-in ChatGPT image generation and authorized
local composition. Each six-role set shares one fixed neutral base; mouth and
eyelid components were registered locally before the production compositor
derived exact pairs. Source hashes, generation prompt, registration and selected
regions are recorded in [codec/inventory.json](codec/inventory.json).
