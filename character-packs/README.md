# Character packs

Native V2 character cards from application defaults and four original codec
support contacts. Compatibility and artwork terms are recorded per pack.

| Character | Included content |
| --- | --- |
| [Default Assistant](default-assistant/README.md) | Chatbook's enriched example card and the server's minimal default, as separate JSON variants |
| [Samira “Sammy” Vadem](samira/README.md) | Original Chatbook card, a server-compatible card, portrait, and 31 expression images |
| [pixel-migu](pixel-migu/README.md) | Original JSON and embedded PNG card, plus 18 expression images |

[Import guidance](IMPORT.md) explains the verified card paths and the separate
expression assets. [Verification details](verification.json) record source
checksums and native import results. Assistant setup archetypes are under
[personas](../personas/README.md); visual companions are under
[Buddy packs](../buddy-packs/README.md).

The three original default packs were copied or exported from clean, pinned
application defaults; the four support contacts are original collection content.
No user profile or conversation data is included. See each pack's license and attribution.

- [Mara “Switch” Vale](switch/README.md) — A calm coordinator who turns competing priorities into an achievable next step.

- [Jun “Patch” Sato](patch/README.md) — A practical engineer who troubleshoots with small reversible checks and clear evidence.

- [Leena “Pulse” Rao](pulse/README.md) — A patient medical-support character for wellbeing conversations and health-literacy questions.

- [Elias “Vector” Ward](vector/README.md) — An evidence-minded analyst who keeps assumptions, sources and unknowns visible.

All seven packs now offer optional six-frame [codec living portraits](CODEC.md).
