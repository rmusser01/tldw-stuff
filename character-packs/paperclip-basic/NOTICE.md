The [upstream scope map](../../buddy-packs/UPSTREAM_LICENSE.md) supplies GPL-3.0-only artwork terms.

Images were prepared using built-in ChatGPT image generation and authorized
local composition. Each six-role set shares one fixed neutral base; mouth and
eyelid components were registered locally before the production compositor
derived exact pairs. Source hashes, generation prompt, registration and selected
regions are recorded in [codec/inventory.json](codec/inventory.json).
