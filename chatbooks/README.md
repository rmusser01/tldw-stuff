# Chatbooks

Shareable knowledge packs and reference collections for tldw_chatbook and
tldw_server. Each pack brings together curated material about a subject for
users to import into their own installation.

No published items yet.

## Adding a knowledge pack

Use one directory per pack, such as `chatbooks/gardening-basics/`. Include:

- A description of the subject, scope, and intended use.
- An inventory of the included material and any external resources it needs.
- The native export format and exact, verified import steps for each supported app.
- The tested application version or commit, date, and import result.
- Source attribution and redistribution terms for all included material.

Share a curated export, not a live user database or private workspace. Keep
small manifests, documentation, and previews in Git. For large packs, link to
a versioned release asset with its size and SHA-256 checksum, following the
[contribution guide](../CONTRIBUTING.md).

Start from the [content README template](../templates/content-README.md).
Add a relative link and short description here when publishing a pack.
